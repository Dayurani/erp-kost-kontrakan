# ERP Kost / Kontrakan

Sistem ERP sederhana untuk manajemen kosan dan kontrakan.

## Fitur
- Data kamar
- Penghuni
- Pembayaran bulanan
- Tagihan / invoice
- Status kamar kosong / terisi

## Cara melihat
1. Buka file `finalproject.html` di browser.
2. Atau jalankan Live Server bila Anda menggunakan ekstensi Live Server di VS Code.

## Siap dipublikasi
Saya sudah menyiapkan salinan `index.html` sehingga situs ini mudah dipublikasikan ke layanan hosting statis.

## Cara membuat link publik
Pilih salah satu layanan berikut dan upload folder `programming for business` atau file `index.html`:

- **Netlify**
  1. Buka https://app.netlify.com/
  2. Login atau daftar gratis.
  3. Pilih "New site from Git" atau drag-and-drop folder yang berisi `index.html`.
  4. Setelah deploy selesai, Netlify memberikan URL publik.

- **GitHub Pages**
  1. Buat repository baru di GitHub.
  2. Upload file `index.html` dan `README.md`.
  3. Aktifkan GitHub Pages dari Settings > Pages > Branch `main` > folder `/`.
  4. GitHub Pages akan memberikan URL seperti `https://username.github.io/repository-name`.

- **Vercel**
  1. Buka https://vercel.com/
  2. Login atau daftar.
  3. Pilih "New Project" dan upload folder statis.
  4. Dapatkan URL publik setelah deploy.

> Standard file publik: `index.html`.

Jika Anda mau, saya bisa bantu buat langkah-langkah GitHub Pages secara lebih terperinci atau bantu menyiapkan file `index.html` agar siap diupload.
